# ABC/XYZ-анализ товарной матрицы ритейла

## О проекте
Проект посвящен управлению ассортиментом торговой сети на основе комбинированного **ABC/XYZ-анализа**. Инструмент позволяет коммерческому отделу и категории менеджерам оптимизировать товарные запасы, выявить ключевые генераторы выручки и оценить стабильность спроса.

## Используемый стек
* **SQL (SQLite):** извлечение данных, агрегация выручки и объемов продаж по артикулам (`GROUP BY`, `SUM`, `ORDER BY`).
* **Python (Pandas, NumPy):** расчет накопительной выручки, коэффициента вариации (`cv`) для оценки стабильности спроса, слияние датасетов.
* **Matplotlib:** визуализация результатов ABC-анализа (круговая диаграмма долей выручки).

## Этапы реализации
1. **Подготовка и очистка данных:** фильтрация транзакций онлайн-ритейла, удаление возвратов и пропусков.
2. **SQL-запросы:** построение агрегированных витрин данных о продажах прямо в памяти с помощью `sqlite3`.
3. **ABC-анализ:** ранжирование ассортимента по правилу Парето (категории A, B, C по вкладу в общую выручку).
4. **XYZ-анализ:** оценка стабильности спроса по коэффициенту вариации (категории X, Y, Z).
5. **Матрица ABC/XYZ:** создание сводной классификации товаров (например, `AX`, `AZ`) для принятия управленческих решений по закупкам.

## Результаты
* Выделена группа товаров **A** (80% выручки при 810 позициях), требующая непрерывного контроля наличия на складе.
* Построена комбинированная матрица и сохранен готовый датасет с сегментацией в файл `abc_xyz_segmented_products.csv`.
